# Обновление ядра — 23 октября 2026

Пять прямых зависимостей OMP обновлены с 18.11.1 до **18.12.6**.
`bun.lock` и `package-lock.json` фиксируют согласованные версии всех 18 пакетов
семейства `@oh-my-pi`; версии сторонних зависимостей сохранены.
Версия подтверждена через npm registry и [стабильный релиз upstream](https://github.com/can1357/oh-my-pi/releases/tag/v18.12.6).

## Изменения upstream

- [18.12.5](https://github.com/can1357/oh-my-pi/releases/tag/v18.12.5): исправлен HTTP 404 у личных ChatGPT-аккаунтов, чей Codex-токен не закреплён за регионом.
- [18.12.4](https://github.com/can1357/oh-my-pi/releases/tag/v18.12.4): исправлены ложные ошибки 429 в Google Antigravity при запросах чата, изображений и веб-поиска.
- [18.12.3](https://github.com/can1357/oh-my-pi/releases/tag/v18.12.3): Gemini корректно сопоставляет результаты параллельных вызовов одного инструмента, даже когда история хранит результаты в другом порядке.
- [18.12.6](https://github.com/can1357/oh-my-pi/releases/tag/v18.12.6): отключено ненужное сжатие простаивающих сессий ChatGPT; исправлено наследование явно пустых цепочек резервных моделей у субагентов.

## Совместимость приложения

Селектор расширений принимает как строки, так и варианты SDK `{label, description}`.
Пользователь видит подпись с описанием, а расширение получает исходный `label`.
Ответ, которого не было среди предложенных вариантов, отклоняется; отмена
завершает ожидание без разрешения действия.

Пресеты GPT + Gemini теперь назначают все **11 диалоговых ролей** SDK.
`tiny` и `widget` используют выбранную Gemini-модель. `memory` использует Gemini
в пресетах «Баланс» и «Gemini + ревью GPT», GPT — в «Качество».
Роли изображений, веб-поиска, речи, диктовки и judge не перезаписываются.
Назначение `memory` не включает систему памяти, а `advisor` — автоматическое ревью.

## Проверки ядра

- 94 проверки адаптеров SDK: RPC, завершение сессий, переключение моделей, история, авторизация, команды и goal mode — пройдены.
- После исправления селектора: 21 RPC-проверка, включая структурированные варианты, совпадающие подписи, неизвестный ответ и отмену — пройдена.
- После расширения пресетов: 8 проверок ролей, API и локализации — пройдены. Проверка состава пресетов сначала воспроизвела отсутствие трёх ролей, затем прошла; состав сравнивается с `CHAT_MODEL_ROLE_IDS` установленного SDK.

Эти проверки используют синтетические данные. Они не подтверждают устранение
регионального HTTP 400 Google или восстановление отозванного OAuth-токена.
Проверка упакованного EXE и публикация релиза выполняются отдельно.
