# Устранение неполадок

[English](../en/TROUBLESHOOTING.md) · [Установка и откат](INSTALLATION.md)

| Симптом | Что проверить |
| --- | --- |
| ChatGPT отсутствует в списке | Откройте «Подключения» и проверьте вход через OAuth. Ключ OpenAI API подключает отдельного провайдера. |
| Пропал прежний вход Antigravity | OMP приостановил этот способ. Настройте официальный CLI по [руководству по режимам](AI_MODES.md) или отдельно подключите Gemini API. |
| Задача сообщает об исчерпании квоты | Проверьте «Лимиты использования» или официальный клиент Antigravity. Оставьте задачу на паузе до восстановления провайдера. |
| Задача не может прочитать файл | Укажите отслеживаемый Git файл в UTF-8 из выбранного проекта. Незакоммиченные правки и исключённые пути с учётными данными задаче недоступны. |
| Патч больше не применяется | Проверьте репозиторий и сравните текущий файл с базовым коммитом задачи. Разберите конфликты вручную. |
| Ошибка установки или обновления | Сверьте хеш файла и версию Bun. Закройте процесс и восстановите предыдущий проверенный EXE или резервную копию установки. Сохраните профиль OMP. |

Для проверки реального входа и ответов используйте [инструкцию](LIVE_VERIFICATION.md). В сообщении об ошибке укажите провайдера, время, этап и статус. Исключите из журналов учётные данные и содержимое проекта.
