# momp 1.6.1

- Войти в Google Antigravity можно из раздела **Подключения** до выбора проекта. momp находит CLI в стандартной папке Google, позволяет перепроверить установку и отменить вход. Если открыть Antigravity во время загрузки проекта, история появится после восстановления проекта.
- Меню проекта помещается в окне на компьютере и телефоне. Escape закрывает меню и возвращает фокус к кнопке проекта.
- Проводник открывает корень диска, явно выбранный в Windows. Если папка проекта перемещена, проводник и **Навыки** предлагают выбрать другую папку.

Вход с реальным аккаунтом Google остаётся в статусе **PENDING LIVE VERIFICATION**. Для работы нужен официальный CLI. См. [режимы AI](AI_MODES.md) и [порядок ручной проверки](LIVE_VERIFICATION.md).

## Режимы провайдеров

Работайте с ChatGPT через вход Codex, с Gemini в чате Antigravity или с обеими моделями в задачах AI. Чат Antigravity использует официальный CLI и поддерживает выбор модели и уровня рассуждений, потоковые ответы, разрешения на действия и историю диалогов. Gemini API и OpenAI API остаются отдельными подключениями. Окно лимитов сохраняет данные провайдеров и показывает обратный отсчёт, когда известно точное время восстановления.

## Задачи и рабочая область

Проверьте diff и результаты запрошенных тестов в контейнере без сети перед применением патча. Задачи AI могут откатить свои патчи после сверки рабочих файлов. Модели и список файлов выбираются перед запуском. Композер остаётся читаемым при открытом редакторе. В мобильных настройках доступен поиск, а центр обновлений показывает статус и инструкции отката.

## Совместимость и проверки

Oh My Pi 18.18.5, Bun 1.4.4, Next.js 16.4.3, React 19.2.8 и Tauri 2.11.5. Сессии, настройки и учётные данные OMP остаются в существующих хранилищах. Секреты из поддерживаемых полей MCP остаются на сервере.

Переносимый EXE Windows поставляется без подписи Authenticode. Опубликованный кандидат запустился под Bun 1.4.4 и сформировал запрос авторизации OpenAI. Google Antigravity CLI 1.5.4 установил соединение по ACP v1 на Windows. Вход в реальные аккаунты, ответы и квоты [ожидают ручной проверки](LIVE_VERIFICATION.md). Условия выпуска указаны в [журнале разработки](../IMPLEMENTATION_PROGRESS.md). Снимки приложения собраны в [галерее](../screenshots/next/README.md).
