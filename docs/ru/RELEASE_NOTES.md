# momp 1.6.0-rc.1

[English](../en/RELEASE_NOTES.md) · [Установка и откат](INSTALLATION.md) · [Проверка реальных подключений](LIVE_VERIFICATION.md)

Ветка кандидата 1.6 обновляет Oh My Pi до 18.18.5 и фиксирует Bun 1.4.4 для локального запуска, CI и настольной сборки. Версии Next.js 16.4.3, React 19.2.8 и Tauri 2.11.5 сохранены.

Раздел **Задачи AI** добавляет запуск с одним провайдером, работу исполнителя и ревьюера, двойное ревью и выбор по типу задачи. Панель показывает модели, этапы, результаты и Git-патч для скачивания. Незавершённые этапы можно повторить отдельно. Рабочая копия проекта остаётся доступной для другой работы.

В **Подключениях** отдельно представлены ChatGPT OAuth, OpenAI API, Gemini API и официальный Antigravity CLI. Окно **Лимиты использования** сохраняет неизвестные значения, обновляется при просмотре и показывает время сброса, когда провайдер его сообщает.

Чат и хранилище учётных данных SDK сохранены. Официальная интеграция Antigravity доступна через `agy` в задачах AI. Прежний Antigravity OAuth приостановлен в OMP. Тесты проекта и применение патча выполняются вручную. Реальный вход, ответы моделей и квоты аккаунтов [ожидают проверки](LIVE_VERIFICATION.md).

Результаты тестов, оставшиеся условия релиза и команды сборки приведены в [журнале реализации](../IMPLEMENTATION_PROGRESS.md).
