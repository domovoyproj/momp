# PENDING LIVE VERIFICATION

[English](../en/LIVE_VERIFICATION.md) · [Подключение провайдеров](AI_MODES.md)

Возьмите временный Git-проект с одним текстовым файлом в коммите. Исключите учётные данные и содержимое проекта из отчётов.

1. Подключите только ChatGPT через **Подключения → ChatGPT**. Выберите модель и уровень рассуждений. Попросите агента изучить файл и откройте сохранённую сессию. Проверьте квоту и сообщённое время восстановления, затем выйдите из аккаунта и войдите снова.
2. В чистом профиле без установленного Antigravity и без выбранного проекта откройте **Подключения → Google Antigravity → Войти через Google**. Дождитесь, когда momp подготовит компонент и откроет браузер. В отдельном окне Edge от momp войдите в аккаунт Google и вернитесь в momp. Откройте тестовый проект, начните диалог, выберите модель Gemini и попросите прочитать файл. Проверьте запросы разрешений, историю и раздел **Лимиты**. Перезапустите momp и убедитесь, что диалог открывается без повторной загрузки компонента.
3. Если используете Gemini API, настройте его отдельно. Запустите обычный чат с чтением файла и проверьте, что сохранённая сессия открывается.
4. Подключите оба провайдера. Запустите задачу с GPT и затем с Gemini в роли исполнителя. Проверьте указанную модель, diff, результаты тестов и независимое ревью. Убедитесь, что рабочие файлы меняются после **Подтвердить применение**, затем отмените патч. При реальной ошибке квоты или соединения проверьте паузу, явный повтор и запуск отдельной задачи с другим провайдером.

Запишите результаты отдельно для OAuth, списка моделей, разрешений, ответов, отчётов о квотах и восстановления. Автоматические тесты используют локальные имитаторы провайдеров.

## Проверка Xbox DNS

В Windows momp автоматически использует Xbox DNS для узлов Google при загрузке компонента, входе в браузере и запросах моделей. Для входа в Antigravity не нужны ручные настройки DNS, API-ключ или вставка кода авторизации. Сервер по умолчанию включает `MOMP_XBOX_DNS=1`; это параметр реализации, а не шаг настройки. На других платформах автоматический браузерный маршрут пока недоступен.

Для входа используется установленный Microsoft Edge с отдельным постоянным профилем momp. Cookies из обычного браузера не копируются, поэтому при первом входе Google может попросить логин, пароль и двухфакторное подтверждение. Следующие попытки используют сохранённый выбор аккаунта в этом профиле. Официальный CLI отводит на авторизацию около 60 секунд: если этого не хватило для первого входа, снова нажмите **Войти через Google**. Браузерный профиль сохраняется.

Временный помощник получает только URL официального callback Antigravity и передаёт одноразовый код официальному CLI. У него нет разрешения читать страницы Google Account или cookies. Обмен OAuth и хранение учётных данных выполняет CLI. Edge может показать уведомление о расширении разработчика; momp его не скрывает. Политики управляемого браузера могут запретить помощник. Тогда вход завершится понятной ошибкой, без незаметного открытия браузера в обход маршрута. [Уведомление Edge](https://support.microsoft.com/en-au/edge/developer-mode-extension-notification)

Для живой проверки выполните шаг 2 выше, отправьте настоящий запрос модели и проверьте сохранённый вход после перезапуска momp. Если используете Gemini API, отдельно проверьте запрос через это подключение. Записывайте ошибки входа, получения списка моделей и ответов независимо. Открытие публичной страницы или искусственный callback не доказывают, что реальный аккаунт может войти и пользоваться моделью.

### Необязательная диагностика соединения

Команда PowerShell ниже нужна только для поиска причины ошибки. Для установки и входа выполнять её не требуется. Она разрешает публичные адреса Google через Xbox DNS по HTTPS. Какие домены направляются через шлюз, решает Xbox DNS; успешного DNS-ответа недостаточно, чтобы подтвердить маршрут HTTPS через шлюз. [Сервис Xbox DNS](https://xbox-dns.ru/)

```powershell
$googleEndpoints = @(
  'https://storage.googleapis.com/antigravity-public/'
  'https://accounts.google.com/'
  'https://oauth2.googleapis.com/'
  'https://cloudcode-pa.googleapis.com/'
  'https://daily-cloudcode-pa.googleapis.com/'
  'https://daily-cloudcode-pa.sandbox.googleapis.com/'
  'https://generativelanguage.googleapis.com/v1beta/models'
)
foreach ($url in $googleEndpoints) {
  curl.exe --disable --head --silent --show-error --max-time 10 --noproxy '*' `
    --doh-url https://xbox-dns.ru/dns-query --output NUL `
    --write-out '%{url_effective} HTTP %{http_code}\n' -- $url
}
```

Код HTTP, включая `4xx`, подтверждает ответ узла по HTTPS, но не авторизацию аккаунта или ответ модели. Для проверки загрузки подставьте URL файла для своей платформы из [манифеста Antigravity](../../lib/antigravity-runtime.ts) и ожидайте `200`.

### Подтверждённые проверки и оставшиеся живые сценарии

- Тест в Windows полностью загрузил Antigravity CLI 1.5.5 во временный профиль и сверил SHA-512 с закреплённым значением.
- Отдельный профиль Edge открыл публичную страницу входа Google через Xbox DNS туннель приложения с сохранённой проверкой TLS. Искусственный callback проверил автоматическую передачу кода без аккаунта.
- 11 ноября 2026 года сайт Xbox DNS сообщал о недоступности сервиса. Его резолвер возвращал `0.0.0.0` и `::` для `generativelanguage.googleapis.com`; запрос к Gemini API завершался ошибкой. momp отклоняет такие адреса и не переключает DNS незаметно.
- **PENDING LIVE VERIFICATION:** вход в реальный аккаунт Google, настоящие ответы Antigravity/Gemini, список доступных моделей, квоты аккаунта и восстановление после повторной авторизации. Публичные узлы и искусственные сценарии не заменяют эти проверки.

Если Xbox DNS не возвращает пригодный адрес или не устанавливает соединение, повторите попытку после восстановления сервиса. Приложение не может восстановить внешний DNS-сервис или изменить правила доступа Google для аккаунта и региона.
