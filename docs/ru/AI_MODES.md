# Подключения и режимы AI

[English](../en/AI_MODES.md) · [Задачи AI и совместный режим](HYBRID_MODE.md) · [Проверка реальных подключений](LIVE_VERIFICATION.md)

- **ChatGPT.** Откройте **Подключения → ChatGPT** и войдите через Codex OAuth в OMP. Выберите модель и уровень рассуждений в поле ввода. Ключ OpenAI Platform подключается через отдельного провайдера OpenAI API с собственной тарификацией.
- **Gemini API.** Откройте **Подключения → Gemini API** и настройте ключ Google AI Studio. Выберите модель Gemini в поле ввода. В этом режиме доступны обычный чат OMP, инструменты, файлы и сессии. Расходы учитываются в Gemini API.
- **Google Antigravity.** Настройте [официальный CLI](https://antigravity.google/docs/cli/install) и войдите в нём. До запуска momp задайте `MOMP_ANTIGRAVITY_CLI` с абсолютным путём к доверенному файлу `agy`. В разделе **Задачи AI** выберите **Google Antigravity CLI**, затем выберите или введите идентификатор Gemini из `agy models`. Интеграция запускает CLI в режиме планирования во временной папке и получает предложения и ревью. OMP 18.18.5 приостановил прежний Antigravity OAuth и сохранил существующие учётные данные.

GPT и Gemini можно использовать по отдельности. Для совместной работы укажите двух провайдеров. Роли в настройках OMP относятся к чату. Роли исполнителя и ревьюеров задаются для каждой задачи отдельно.

Окно **Лимиты использования** показывает данные SDK, известные времена сброса и отсутствующие значения. Пока окно открыто, данные обновляются. Для настроенного Antigravity CLI версии 1.5.0 или новее окно также показывает официальный отчёт `/usage`, когда CLI его возвращает. При исчерпании квоты повторите задачу после восстановления или явно подготовьте отдельную задачу с другой моделью. Когда исполнитель закончил, задачу можно завершить без оставшихся ревью.
