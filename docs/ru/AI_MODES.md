# Подключения и AI-режимы

[English](../en/AI_MODES.md) · [Совместный режим](HYBRID_MODE.md) · [Ручная проверка](LIVE_VERIFICATION.md)

## ChatGPT

Откройте **Подключения → ChatGPT** и завершите вход через Codex в браузере. Откройте проект и выберите модель ChatGPT и уровень рассуждений в панели ввода основного чата. В чате доступны файлы, инструменты, Git и сохранённые сессии. Для ключей платформы OpenAI есть отдельное подключение **OpenAI API** со своей тарификацией.

## Google Antigravity

1. Установите [официальный Antigravity CLI](https://antigravity.google/docs/cli/install) и проверьте команду `agy acp --help`. Для встроенного отчёта об использовании нужен CLI 1.5.0 или новее.
2. Перед запуском momp задайте полный путь к доверенному файлу `agy` в `MOMP_ANTIGRAVITY_CLI`. В Windows PowerShell выполните `$env:MOMP_ANTIGRAVITY_CLI = (Get-Command agy.exe).Source` и запустите momp из той же сессии. В Linux и macOS выполните `export MOMP_ANTIGRAVITY_CLI="$(command -v agy)"`.
3. Откройте проект и выберите **Чат Antigravity**. Кнопка **Войти через Google** откроет вход CLI в браузере на компьютере, где запущен momp. Учётные данные хранит CLI. На сервере без браузера выполните вход командой `agy acp --login` на самом сервере.
4. Проверьте доверие к проекту и подтвердите доступ инструментов Antigravity. Нажмите **Начать диалог**. Выберите модель и уровень рассуждений из вариантов CLI. Если CLI запрашивает разрешение, действие можно отклонить или разрешить один раз. Также действуют правила доступа и изоляция терминала CLI.
5. Откройте диалог из истории и нажмите **Продолжить диалог**, если он отключён. Приложение хранит последние записи переписки, а CLI восстанавливает контекст своего диалога.

Режим работает независимо от ChatGPT. Gemini API тоже доступен отдельно. Добавьте ключ Google AI Studio в **Подключения → Gemini API** и выберите модель Gemini в основном чате OMP. OMP сохраняет прежние учётные данные приостановленной интеграции Antigravity.

## Совместный режим и лимиты

В **Задачах AI** можно выбрать GPT, Gemini или обе модели. Если CLI настроен, выберите **Google Antigravity CLI** для роли Gemini и модель из списка `agy models`. Порядок работы и разрешения описаны в [руководстве по совместному режиму](HYBRID_MODE.md).

Окно **Лимиты** обновляет отчёты, пока открыто. Оно показывает сообщённое провайдером время восстановления, отмечает недоступные значения и сохраняет последний успешный отчёт при ошибке обновления. Для Antigravity используется отчёт CLI `/usage`. Обратный отсчёт отображается, если в нём есть время с часовым поясом. При исчерпании квоты сохраните или приостановите работу, дождитесь восстановления либо явно выберите доступную модель.
