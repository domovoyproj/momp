# Подключения и AI-режимы

## ChatGPT

Откройте **Подключения → ChatGPT** и завершите вход через Codex в браузере. Откройте проект и выберите модель ChatGPT и уровень рассуждений в панели ввода основного чата. В чате доступны файлы, инструменты, Git и сохранённые сессии. Для ключей платформы OpenAI есть отдельное подключение **OpenAI API** со своей тарификацией.

## Google Antigravity

1. На компьютере, где запущен momp, откройте **Подключения → Google Antigravity → Войти через Google**. Это можно сделать до выбора проекта.
2. В Windows momp при необходимости подготовит официальный компонент и откроет отдельное окно Microsoft Edge через Xbox DNS. Войдите в аккаунт Google и вернитесь в momp. Настраивать DNS, вводить API-ключ или копировать код авторизации не нужно. Первая загрузка Windows x64 составляет около 226 МБ; momp проверяет файл с сервера Google и использует его при следующих запусках. Обмен OAuth и хранение учётных данных выполняет официальный CLI Google. [Справочник официального CLI](https://antigravity.google/docs/cli/reference/)
3. Откройте проект и выберите **Чат Antigravity**. Проверьте доверие к проекту, подтвердите доступ инструментов и нажмите **Начать диалог**. Если Antigravity запрашивает разрешение, действие можно отклонить или разрешить один раз.
4. Чтобы вернуться к переписке, выберите диалог из истории и нажмите **Продолжить диалог**.

### Автоматический маршрут Google в Windows

Сервер Windows по умолчанию использует Xbox DNS для загрузок Google, входа и запросов моделей. Для автоматического входа в Antigravity нужен установленный Edge. momp использует собственный браузерный профиль; настройки и cookies вашего обычного браузера остаются отдельно. При первом входе Google может запросить пароль и двухфакторное подтверждение. Выбор аккаунта может сохраняться для следующих попыток.

Официальный CLI отводит на авторизацию около 60 секунд. Если первый вход не успел завершиться, снова нажмите **Войти через Google**; браузерный профиль momp сохраняется. Узкий временный помощник передаёт CLI только одноразовый код из официального callback Antigravity. Edge может показать уведомление о расширении разработчика; momp его не скрывает. Если политики управляемого браузера запрещают помощник, вход завершится ошибкой без изменения политик и перехода на прямое соединение.

Загрузка и браузерный маршрут проверены на публичных узлах Google, автоматическая передача callback — на искусственных данных. **Вход в реальный аккаунт и настоящие ответы моделей остаются PENDING LIVE VERIFICATION.** 11 ноября 2026 года Xbox DNS сообщал о недоступности сервиса и возвращал непригодные адреса для узла Gemini API. Приложение показывает ошибки маршрута и не меняет резолвер незаметно. См. [живую проверку и необязательную диагностику](LIVE_VERIFICATION.md).

Загрузка компонента доступна на x64 и ARM64 в Windows, macOS и Linux с glibc. Автоматический браузерный маршрут Xbox DNS пока поддерживается только в Windows и использует подготовленный momp клиент 1.5.5 с проверкой хеша, включая чат и отчёты о лимитах. Другая системная или указанная вручную версия в этом режиме не запускается. Вне этого режима momp переиспользует установленный клиент или путь администратора `MOMP_ANTIGRAVITY_CLI`; для отчётов о лимитах нужна версия 1.5.0 или новее.

Режим работает независимо от ChatGPT. Gemini API тоже доступен отдельно. Добавьте ключ Google AI Studio в **Подключения → Gemini API** и выберите модель Gemini в основном чате OMP. OMP сохраняет прежние учётные данные приостановленной интеграции Antigravity.

## Совместный режим и лимиты

В **Задачах AI** можно выбрать GPT, Gemini или обе модели. После входа через Google выберите **Google Antigravity CLI** для роли Gemini и модель из списка в том же окне. Порядок работы и разрешения описаны в [руководстве по совместному режиму](HYBRID_MODE.md).

Окно **Лимиты** обновляет отчёты, пока открыто. Оно показывает сообщённое провайдером время восстановления, отмечает недоступные значения и сохраняет последний успешный отчёт при ошибке обновления. Для Antigravity используется отчёт CLI `/usage`. Обратный отсчёт отображается, если в нём есть время с часовым поясом. При исчерпании квоты сохраните или приостановите работу, дождитесь восстановления либо явно выберите доступную модель.
