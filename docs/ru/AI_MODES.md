# Подключения и AI-режимы

[English](../en/AI_MODES.md) · [Совместный режим](HYBRID_MODE.md) · [Ручная проверка](LIVE_VERIFICATION.md)

## ChatGPT

Откройте **Подключения → ChatGPT** и завершите вход через Codex в браузере. Откройте проект и выберите модель ChatGPT и уровень рассуждений в панели ввода основного чата. В чате доступны файлы, инструменты, Git и сохранённые сессии. Для ключей платформы OpenAI есть отдельное подключение **OpenAI API** со своей тарификацией.

## Google Antigravity

1. На компьютере, где запущен momp, откройте **Подключения → Google Antigravity → Войти через Google**. Это можно сделать до выбора проекта.
2. Выберите аккаунт Google в браузере и вернитесь в momp. При первом входе momp при необходимости сам скачает компонент с сервера Google, проверит его и сохранит для следующих запусков. В Windows x64 первая загрузка составляет около 226 МБ. Учётные данные хранит официальный клиент Google. [Как устроен вход Antigravity](https://antigravity.google/docs/ide/extensions/acp#authentication)
3. Откройте проект и выберите **Чат Antigravity**. Проверьте доверие к проекту, подтвердите доступ инструментов и нажмите **Начать диалог**. Если Antigravity запрашивает разрешение, действие можно отклонить или разрешить один раз.
4. Чтобы вернуться к переписке, выберите диалог из истории и нажмите **Продолжить диалог**.

Автоматическая подготовка доступна на x64 и ARM64 в Windows, macOS и Linux с glibc. Если официальный клиент уже установлен, momp переиспользует его. Для нестандартной установки администратор может указать абсолютный путь в `MOMP_ANTIGRAVITY_CLI`. Для отчётов о лимитах нужен клиент версии 1.5.0 или новее.

Режим работает независимо от ChatGPT. Gemini API тоже доступен отдельно. Добавьте ключ Google AI Studio в **Подключения → Gemini API** и выберите модель Gemini в основном чате OMP. OMP сохраняет прежние учётные данные приостановленной интеграции Antigravity.

## Совместный режим и лимиты

В **Задачах AI** можно выбрать GPT, Gemini или обе модели. После входа через Google выберите **Google Antigravity CLI** для роли Gemini и модель из списка в том же окне. Порядок работы и разрешения описаны в [руководстве по совместному режиму](HYBRID_MODE.md).

Окно **Лимиты** обновляет отчёты, пока открыто. Оно показывает сообщённое провайдером время восстановления, отмечает недоступные значения и сохраняет последний успешный отчёт при ошибке обновления. Для Antigravity используется отчёт CLI `/usage`. Обратный отсчёт отображается, если в нём есть время с часовым поясом. При исчерпании квоты сохраните или приостановите работу, дождитесь восстановления либо явно выберите доступную модель.
