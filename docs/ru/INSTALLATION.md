# Установка, обновление и откат

[English](../en/INSTALLATION.md) · [Руководство](USER_GUIDE.md)

Для стабильной версии откройте [релизы GitHub](https://github.com/domovoyproj/momp/releases) и скачайте переносимый EXE для Windows или следуйте инструкции установки веб-версии. Сверьте SHA-256 файла с указанным в релизе. В Windows используйте `Get-FileHash .\momp.exe -Algorithm SHA256`. Предварительные сборки проверяются отдельно и не входят в канал стабильных обновлений.

Для запуска из исходников установите Git и Bun 1.4.4 или новее, затем выполните в корне репозитория:

```sh
bun install --frozen-lockfile
bun run dev
```

Откройте `http://127.0.0.1:30141` и выберите Git-проект. Для нативной сборки под Windows также нужны Rust, инструменты сборки Visual C++ и WebView2.

Откройте **Центр обновлений** в боковой панели, чтобы увидеть установленную и последнюю стабильную версии, проверить обновления или прочитать инструкцию отката. Перед установкой дождитесь завершения активных задач. При стабильном обновлении Windows приложение проверяет SHA-256, перезапускается и сохраняет предыдущий EXE как `previous.exe` в папке `.momp-update-*` рядом с `momp.exe`. Для отката закройте momp, сохраните копию текущего EXE и восстановите `previous.exe`. Для веб-версии остановите сервер и восстановите предыдущую установку из резервной копии. Используйте тот же профиль OMP с `agent.db`, настройками и сессиями. Переносимый EXE не подписан Authenticode.
