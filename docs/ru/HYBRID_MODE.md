# Задачи AI и совместный режим

[English](../en/HYBRID_MODE.md) · [Настройка провайдеров](AI_MODES.md)

1. Откройте Git-проект хотя бы с одним коммитом и выберите **Задачи AI** в боковой панели.
2. Выберите один из режимов: только GPT, только Gemini, GPT или Gemini в роли исполнителя, двойное ревью или выбор по типу задачи. В двойном ревью GPT выполняет задачу, а обе модели независимо проверяют результат. При выборе по типу задачи Gemini ведёт работу над интерфейсом, GPT — над реализацией и архитектурой.
3. Опишите задачу. При необходимости укажите до восьми отслеживаемых текстовых файлов UTF-8, по одному пути на строку. Исполнитель получит версии из коммита. Ревьюеры получат задачу, предложенный diff, вывод исполнителя и результат проверки пробелов Git. Исключайте конфиденциальные данные из запроса и выбранных файлов.
4. Нажмите **Подготовить задачу**, проверьте модели и контекст, затем **Подтвердить и запустить**. Исполнитель предлагает замены файлов. momp формирует diff во временном Git-репозитории. В этом сценарии ревьюеры не могут записывать в рабочую копию.
5. Прочитайте результаты, скачайте и проверьте патч. В корне нужного проекта выполните `git apply --check /путь/к/задаче.patch`, затем `git apply /путь/к/задаче.patch`. Перед коммитом прогоните тесты проекта. Задача выполняет `git diff --check` для предложения. Тесты запускаются вручную.

Задача и завершённые этапы хранятся локально. Кнопка **Приостановить задачу** останавливает активные этапы. После ошибки или перезапуска **Повторить незавершённые этапы** использует те же модели и сохраняет завершённую работу. На каждый этап выделено три попытки. Когда исполнитель закончил, можно завершить задачу без оставшихся ревью. Если исполнитель недоступен, можно подготовить отдельную задачу с другой моделью и проверить её перед запуском. Параллельные задачи готовят патчи в раздельных временных каталогах.
