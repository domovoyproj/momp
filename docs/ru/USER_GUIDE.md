# Руководство по рабочему пространству

[English](../en/USER_GUIDE.md) · [Установка](INSTALLATION.md) · [Режимы AI](AI_MODES.md) · [Устранение неполадок](TROUBLESHOOTING.md) · [Скриншоты](../screenshots/next/README.md)

Откройте проект через боковую панель, создайте чат и выберите модель в поле ввода. В меню рассуждений доступны уровни, которые поддерживает выбранная модель. Чаты можно открыть из истории. Продолжите с предыдущего сообщения, чтобы создать ветку внутри чата, или сделайте fork в отдельную сессию. В поле ввода доступны остановка ответа и сжатие контекста.

Открывайте и сохраняйте код через проводник и редактор. Панель Git показывает изменённые файлы и diff. Используйте worktree, когда нужны раздельные рабочие копии. В разделе **Задачи AI** выберите пути и модели, проверьте тесты и diff, затем примените или скачайте патч. Подробнее в [руководстве по задачам AI](HYBRID_MODE.md).

В **Подключениях** доступны авторизация и окно **Лимиты**. **Чат Antigravity** подключает официальный Google CLI напрямую. В настройках доступны темы, навыки, плагины и MCP, а в боковой панели — **Центр обновлений**. Перед включением инструментов или MCP проекта проверьте запрос доверия. OMP и Antigravity CLI хранят свои учётные данные локально. Выбранному провайдеру передаются запросы и контекст для выполнения задачи.

Язык интерфейса выбирается на панели инструментов. Tab перемещает фокус между элементами, Escape закрывает диалог. Доступны светлая и тёмная темы.
