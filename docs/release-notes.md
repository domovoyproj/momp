# momp 1.6.2

## English

### Overview

Sign in to Google Antigravity from momp before opening a project. This update also fixes a clipped project menu and restores browsing at Windows drive roots.

### What's New

momp prepares the official Antigravity client when you first select **Sign in with Google**. You can cancel and retry from the same panel. File Explorer and Skills offer a directory picker when the selected project folder is gone.

### AI Providers

momp reuses an existing official client or downloads a verified copy directly from Google on demand. The client opens browser sign-in and stores your credentials. [AI modes](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/en/AI_MODES.md)

### Hybrid AI

After Google sign-in, Antigravity can serve as the Gemini provider for lead and review roles in AI tasks. [Hybrid AI guide](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/en/HYBRID_MODE.md)

### Interface Improvements

The project menu opens over the sidebar and fits inside the window. Escape closes it and returns focus to the project button. [Desktop and mobile screenshots](https://github.com/domovoyproj/momp/tree/v1.6.2/docs/screenshots/next)

### How to Use

Choose **Connections → Google Antigravity → Sign in with Google**, complete sign-in in the browser, then open a project to start or reconnect a conversation.

### Installation / Upgrade

Verify the SHA-256 before installing. Keep your previous installer for rollback. [Installation and rollback](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/en/INSTALLATION.md)

### Bug Fixes

An explicitly selected drive root now opens in File Explorer. Skills reports a missing project folder and links to the directory picker. Antigravity loads the conversation history when the workspace finishes restoring after a reload.

### Compatibility

Oh My Pi 18.18.5 and Bun 1.4.4. Automatic setup uses Antigravity 1.5.5. On Windows x64 the one-time download is about 226 MB.

### Known Issues

Google sign-in, responses and quotas with a real account remain **PENDING LIVE VERIFICATION**. [Live verification checklist](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/en/LIVE_VERIFICATION.md)

### Download

The assets below include the Windows EXE, web distribution, browser verification archive and SHA-256 checksums.

## Русский

### Обзор обновления

Войти в Google Antigravity можно из momp до выбора проекта. В этой версии также исправлено обрезание меню проекта и открытие корня диска в Windows.

### Что нового

При первом нажатии **Войти через Google** momp подготовит официальный компонент Antigravity. Отменить и повторить вход можно в той же панели. Если выбранная папка исчезла, проводник и **Навыки** предлагают выбрать другую.

### AI-провайдеры

momp использует уже установленный официальный компонент или скачивает проверенную копию напрямую у Google. Компонент открывает вход в браузере и хранит учётные данные. [Режимы AI](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/ru/AI_MODES.md)

### Совместный режим

После входа через Google можно выбрать Antigravity в роли Gemini для выполнения и ревью в **Задачах AI**. [Руководство по совместному режиму](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/ru/HYBRID_MODE.md)

### Улучшения интерфейса

Меню проекта открывается поверх боковой панели и помещается в окне. Escape закрывает меню и возвращает фокус к кнопке проекта. [Скриншоты на компьютере и телефоне](https://github.com/domovoyproj/momp/tree/v1.6.2/docs/screenshots/next)

### Как пользоваться

Выберите **Подключения → Google Antigravity → Войти через Google**, завершите вход в браузере, затем откройте проект, чтобы начать или переподключить диалог.

### Установка / обновление

Перед установкой сверьте SHA-256. Сохраните предыдущий установщик для отката. [Установка и откат](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/ru/INSTALLATION.md)

### Исправления

Проводник открывает явно выбранный корень диска. **Навыки** сообщают об исчезнувшей папке проекта и предлагают выбрать другую. После перезагрузки история диалогов Antigravity появляется, как только проект восстановлен.

### Совместимость

Oh My Pi 18.18.5 и Bun 1.4.4. При автоматической подготовке momp использует Antigravity 1.5.5. В Windows x64 первая загрузка занимает около 226 МБ.

### Известные проблемы

Вход в Google, ответы и квоты на реальном аккаунте остаются в статусе **PENDING LIVE VERIFICATION**. [Порядок ручной проверки](https://github.com/domovoyproj/momp/blob/v1.6.2/docs/ru/LIVE_VERIFICATION.md)

К релизу приложены EXE для Windows, веб-сборка, архив браузерных проверок и контрольные суммы SHA-256.
