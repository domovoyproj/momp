# momp 1.4.0 — совместное пространство GPT + Gemini

## Новый интерфейс
- Тёплая светлая и графитовая тёмная темы, новая боковая панель, заметная кнопка нового чата и отдельные входы в подключения и библиотеку skills.
- Новый стартовый экран и карточки задач; подсказки заполняют редактор, но не отправляют сообщение без вашего действия.
- Нативные кнопки закрытия, сворачивания и разворачивания в стиле macOS. Системная рамка остаётся резервным вариантом, если desktop-мост недоступен.

## ChatGPT + GitHub + Antigravity
- Приоритетные карточки ChatGPT/Codex, GitHub Copilot и Antigravity; существующие OAuth-подключения и API-провайдеры сохраняются.
- Три пресета ролей: «Баланс», «Качество», «Gemini + ревью GPT». Выбирайте конкретные доступные GPT/Gemini-модели, просматривайте распределение ролей и применяйте его глобально или для проекта.
- Пресеты не включают автоматическое ревью сами по себе и не обещают доступ к моделям, отсутствующим у вашего аккаунта.
- Локальный GitHub origin и ветка в боковой панели; быстрые ссылки на репозиторий, PR и Actions. Для чтения локального Git-репозитория нужен установленный Git.

## Общая библиотека skills
- Обнаружение `.agents/skills`, `$CODEX_HOME/skills` / `~/.codex/skills`, Gemini и Antigravity, включая проектные каталоги.
- Один загрузчик для списка skills и рабочих сессий, обновление после reload, сохранение относительных путей ресурсов.
- Учитывается `agents/openai.yaml → policy.allow_implicit_invocation: false`; некорректная политика не включает навык автоматически.
- Совместимость касается формата `SKILL.md` и файлов навыка. Специфические инструменты ChatGPT, коннекторы, Python/Node-зависимости и права доступа должны быть доступны в momp отдельно.

## Движок и обновления
- OMP обновлён с 18.2.8 до 18.11.1; интеграция адаптирована к новым реестрам настроек и пространствам имён авторизации.
- Включены upstream-исправления Gemini tool continuation / reasoning signatures и каталога Antigravity.
- Windows автоматически проверяет GitHub Releases. Кнопка «Обновить и перезапустить» скачивает только официальный `momp.exe`, проверяет размер, SHA-256 из GitHub API и встроенный SFX-пакет, затем заменяет EXE после закрытия приложения.
- Предыдущий EXE сохраняется в соседнем каталоге `.momp-update-*` как `previous.exe`, вместе с журналом обновления. Завершите активные задачи перед перезапуском. Приложение не закрывается самопроизвольно.
- В релиз входят `momp.exe`, `momp-web-dist.tar.gz` и `SHA256SUMS`. Публикация выполняется только после проверок типов, тестов, сборки и запуска самого упакованного Windows EXE с проверкой HTTP/API.

Скачайте **momp.exe** из assets ниже. Это portable-приложение: отдельная установка Bun и Node.js для запуска не нужна. Windows WebView2 должен быть установлен. EXE не имеет Authenticode-подписи; SHA-256 проверяет целостность относительно GitHub, а не заменяет подпись издателя.
