# Workspace guide

[Русский](../ru/USER_GUIDE.md) · [Installation](INSTALLATION.md) · [AI modes](AI_MODES.md) · [Troubleshooting](TROUBLESHOOTING.md) · [Screenshots](../screenshots/next/README.md)

Open a project from the sidebar, then create a chat and choose a model in the composer. The reasoning menu shows the levels offered by the selected model. Existing chats can be reopened from session history. Continue from an earlier message to branch within the conversation, or fork it into a new session. Use the composer controls to stop a run or compact context.

Use the file explorer and editor to inspect and save code. Use the Git panel to inspect changed files and diffs. Use a Git worktree when you want separate working copies. In **AI tasks**, choose the project paths and models, review the tests and diff, then apply or download the patch. See [AI tasks](HYBRID_MODE.md).

Open **Connections** for provider sign-in and **Usage limits**. Use **Antigravity chat** for direct access to Google's official CLI. Settings includes themes, skills, plugins and MCP. **Update center** is in the sidebar. Review the project trust dialog before enabling project tools or MCP configuration. OMP and the Antigravity CLI keep their own local credentials. The selected provider receives prompts and the context submitted for a run.

Change the interface language from the toolbar. Use Tab to move between controls and Escape to dismiss a dialog. Both light and dark themes are available.
