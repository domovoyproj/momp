# Workspace guide

[Русский](../ru/USER_GUIDE.md) · [Installation](INSTALLATION.md) · [AI modes](AI_MODES.md) · [Troubleshooting](TROUBLESHOOTING.md)

Open a project from the sidebar, then create a chat and choose a model in the composer. The reasoning menu shows the levels offered by the selected model. Existing chats can be reopened from session history. Continue from an earlier message to branch within the conversation, or fork it into a new session. Use the composer controls to stop a run or compact context.

Use the file explorer and editor to inspect and save code. Use the Git panel to inspect changed files and diffs. Use a Git worktree when you want separate working copies. In **AI tasks**, choose files committed in Git, review the models and context, and export a proposed patch. See [AI tasks](HYBRID_MODE.md).

Open **Connections** for provider sign-in and **Usage limits**. Settings includes themes, extensions, skills, plugins, MCP and desktop update controls. Review the project trust dialog before enabling project tools or MCP configuration. Sessions and credentials are stored locally in the OMP profile. The selected provider receives prompts and the context submitted for a run.

Change the interface language from the toolbar. Use Tab to move between controls and Escape to dismiss a dialog. Both light and dark themes are available.
